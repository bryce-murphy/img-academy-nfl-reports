# Contributing

Use a branch and pull request. Run `python -m unittest discover -s tests -v`. CI needs no network or credentials.

Keep every alumni affiliation sourced. Do not match players by name at report time. IDs, team, season, week, game, and source timestamps matter. Add a regression case when correcting an accuracy bug.

Never claim injury, illness, or benching from a missing row or zero statistics. Changes to attribution, publication rules, credentials, or workflows deserve explicit review. Do not add direct Pro Football Reference scraping or copy paid tracking data into the repository.
